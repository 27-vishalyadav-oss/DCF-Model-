DCF Valuation of Century Plyboards (India) Ltd.

Project Overview

This project focuses on valuing Century Plyboards (India) Ltd. using the Discounted Cash Flow (DCF) method in Microsoft Excel. The workbook combines historical financial statement analysis, financial forecasting, cost of capital estimation, and projected cash flows to estimate the company's intrinsic value.

Key Areas Covered

Historical Financial Analysis: Analysis of profit and loss statements, balance sheets, and cash flow statements.

Financial Forecasting: Projection of financial performance using historical data and assumptions.

Fixed Asset Schedule: Analysis of property, plant and equipment, capital additions, and depreciation.

Beta Estimation: Estimation of equity beta using market returns and comparable companies.

Weighted Average Cost of Capital (WACC): Calculation of the cost of equity and after-tax cost of debt to estimate the discount rate.

Discounted Cash Flow Valuation: Discounting projected cash flows to estimate enterprise value and derive equity value.

Sensitivity and Valuation Assumptions: Examination of key inputs that influence the valuation, where supported by the workbook.
